# t480-hackintosh
A project running macos on a corebooted Thinkpad T480. Because of compatibility issues, this project has been halted.
If you want to try or fix something by yourself, you can get this efi and use it (Also generate a new smbios).
Laptop specs:
  - CPU: I5 8350U
  - GPU: UHD 620
  - RAM: 16GB DDR4 2400MHz
  - STORAGE: 256GB NVME SSD
What's working:
  - GPU acceleration (buggy even though it has full metal support, black window firefox and kitty is the issue that made me decided to leave this project) 
  - USB ports, USB-C
  - Trackpad, Trackpoint
  - HDMI out
  - Wifi (intel, there are a lot of guides for you to follow and have a working wifi and bt without external apps)
What's not working:
  - Battery (can't boot into macos after install battery)
  - iServices (can patch)
  - Properly app's hardware acceleration.
  - Brightness keys (idk why it won't work even tho i still can change the brightness with settings)
  - Sleep, Power management (unknown)
